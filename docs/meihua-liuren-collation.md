# 梅花易數、大六壬：算法依據與原文核對

## 一、依據

- 《梅花易數》，維基文庫本：`梅花易數/卷一`、`梅花易數/卷二`。
- 《六壬大全》，維基文庫四庫全書本：`六壬大全 (四庫全書本)/卷01`、`卷02`。另用同書標點本 `六壬大全/1` 對讀。
- 兩部書都只按原文算法實作，沒有移植任何程式碼。
- 原文抽取腳本是 `scripts/data/gen-meihua-text.py`，只抽取、不改字。六壬只用到卷一的規則，沒有收原文。

## 四、六壬有異說之處與工具的取法

1. **貴人起法**
   - 《六壬大全》卷一只有「先天陽貴圖」「後天陰貴圖」兩張圖，並自注「其說甚有理，而近不用」；正文沒有寫明當時通行的起法。
   - 工具用通行歌訣「甲戊庚牛羊，乙己鼠猴鄉，丙丁豬雞位，壬癸兔蛇藏，六辛逢馬虎」，前者為晝貴、後者為夜貴，占時卯至申為晝。
   - 貴人所臨地盤在亥至辰則順行，在巳至戌則逆行。
   - 輸出一律附 `⚠ 假設：`。
2. **涉害**
   - 工具照「涉害行來本家止，路逢多克為用取」數深淺：上神從所臨地盤順行回到本位，沿途地支與寄干克它的次數，數多者為用。
   - 相等時依「孟深仲淺季當休」先取臨孟、次取臨仲；再相等依「復等柔辰剛日宜」，剛日取幹上、柔日取支上。
   - 另一派不數深淺、直接取孟仲。兩派初傳不同時，工具兩種三傳都輸出並標假設。
3. **伏吟中末**
   - 照「迤邐刑之作中末」取刑。初傳自刑時，「次傳顛倒日辰併」：初傳取幹上的，中傳改取支上；初傳取支上的，中傳改取幹上。
   - 中傳又自刑時，「沖取末傳不論刑」。
   - 乙、癸日伏吟幹上有克，依「伏吟有克還為用」取幹上。
4. **別責柔日**
   - 依「柔日支前三合取」，取日支三閤中的下一位為初傳，例如酉日取丑。
   - 歌訣下句「皆以天上作初傳」也可以讀成取該位上的天盤神，屬於異讀。工具按通行讀法取地支本身。
5. **月將**：依卷二各神「雨水後日纏娵訾正月將」等，以中氣換將，中氣時刻以東八區計。
