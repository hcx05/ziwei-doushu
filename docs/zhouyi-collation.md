# 《周易》經文校勘記錄

`lib/systems/liuyao/zhouyi.data.ts` 的卦辭、爻辭取自 npm 包 **iching-kit@0.1.0**（MIT），另與獨立轉錄 **@freizl/yijing@2.1.0**（MIT）逐字比對（忽略標點，`scripts/data/collate-zhouyi.py`）。共比對 64 卦 × （卦辭 1 + 爻辭 6）＋ 用九、用六，差異 42 處：

| 類別 | 處數 | 處理 |
|---|---|---|
| 格式 | 6 | 採用本為準 |
| 異體字 / 繁簡寫法 | 22 | 採用本為準 |
| 對照本文字有誤 | 12 | 採用本為準 |
| 歷代版本異文 | 2 | 採用本取「己日」，另一讀法「巳日」見下表 |

結論：對照本錯誤較多（誤植、誤倒、缺字、重複），採用本在所有實質差異上與常見通行本讀法一致。

> 「常見通行本讀法」是校勘者（Claude）依對王弼注《周易正義》、朱熹《周易本義》等通行本的理解作出的判斷，本環境無法連上原書逐一核對；若發現錯誤，請以原書為準修正 `zhouyi.data.ts` 並補充本表。
