# 《周易》经文校勘记录

`lib/systems/liuyao/zhouyi.data.ts` 的卦辞、爻辞取自 npm 包 **iching-kit@0.1.0**（MIT），另与独立转录 **@freizl/yijing@2.1.0**（MIT）逐字比对（忽略标点，`scripts/data/collate-zhouyi.py`）。共比对 64 卦 × （卦辞 1 + 爻辞 6）＋ 用九、用六，差异 42 处：

| 类别 | 处数 | 处理 |
|---|---|---|
| 格式 | 6 | 采用本为准 |
| 异体字 / 繁简写法 | 22 | 采用本为准 |
| 对照本文字有误 | 12 | 采用本为准 |
| 历代版本异文 | 2 | 采用本取「己日」，另一读法「巳日」见下表 |

结论：对照本错误较多（误植、误倒、缺字、重复），采用本在所有实质差异上与常见通行本读法一致。

> 「常见通行本读法」是校勘者（Claude）依对王弼注《周易正义》、朱熹《周易本义》等通行本的理解作出的判断，本环境无法连上原书逐一核对；若发现错误，请以原书为准修正 `zhouyi.data.ts` 并补充本表。
