## 二、流派選擇（D5）

時家奇門的分歧主要在**定局**：同一時刻屬哪個節氣、哪一元。

| | 拆補法 | 置閏法 |
|---|---|---|
| 定節氣 | 按交節時刻 | 上元符頭依序配節氣，符頭先到為「超神」、後到為「接氣」 |
| 定元 | 當日符頭（甲、己日）之支：子午卯酉上元、寅申巳亥中元、辰戌丑未下元 | 符頭起算，每五日一元 |
| 置閏 | 無 | 芒種、大雪超神過九日，重排該節氣三元 |
| 確定性 | 只看節氣時刻與日干支，同一時刻必得同一局 | 置閏日數書中就有「九日或十日或十一日」之說；要從往年一路推來 |
| 古籍 | 《遁甲演義》卷一「又引證」萬曆二十四年一例即用拆補（殘局、補局） | 《遁甲演義》「超神接氣置閏訣」、《御定奇門寶鑑》主張置閏、批評拆補 |

**決定**：以拆補法為準，同時列出置閏法的結果。

- 理由是拆補法沒有閾值爭議，可重現。
- 置閏法有古籍權威，所以不丟棄：兩法得出的局不同時，工具輸出 `⚠ 假設：`，提醒按置閏法盤會不同。
- 1990–2030 年每月四天抽樣，共 1,968 個時刻，兩法局數不同的約三分之一，集中在每個節氣的前段。

置閏法的實作：

- 從距今約五年前，找一個上元符頭與節氣相差兩日內的日子為起點，依序配節氣。
- 芒種、大雪超神「過九日」（十日以上）才置閏；小滿、小雪即使超九日、十日也不置閏（「設遇小滿小雪二氣之交，雖超九日十日不可置閏」）。
- 書中「丙戌年」一例說「超九日則當置閏」，與同書「超過九日即置閏」及《寶鑑》「如過九日，即當置閏」不一致，本工具取「過九日」。
- 書中萬曆年間的例子用的是明代大統曆的平氣，與現代定氣交節時刻可差一兩日，所以置閏規則用合成日數核對，不拿現代曆法套萬曆年。

## 三、排盤規則（轉盤）

- **地盤**：陽遁自局數宮起戊，依宮序 1→9 佈戊己庚辛壬癸丁丙乙；陰遁依 9→1。
- **值符值使**：時辰所屬旬的旬首六儀落宮，該宮的星為值符、門為值使；落中五宮時為天禽、死門。
- **天盤**：值符加時干所落地盤宮（甲時用旬首六儀），九星沿八宮圓周整體轉動。中五寄坤二，天禽隨天芮，天盤同時帶芮、禽兩干。
- **八門**：值使自旬首宮起，按時支距旬首的數目陽順陰逆數九宮，入中寄坤，八門沿圓周整體轉動。
- **八神**：值符所臨之宮起值符，陽遁順時針、陰遁逆時針，依次為值符、螣蛇、太陰、六合、白虎、玄武、九地、九天。
- **坤二宮的地盤**：另含中五宮寄來的干。卷二「六庚下臨六丙於二宮」一例的丙，正是中五寄坤的丙。

**沒有收進測試的一例**：

- 卷二「伏干格」：「小滿上元陽五局甲申日壬申時，六壬在九宮即天柱為六庚下臨九宮」。
- 照書中通則（值符天禽隨天芮，加時干壬於九宮），天柱應到二宮，不在九宮。
- 同書同局的「飛干格」一例（同為陽五局、值符天禽）按同一通則完全吻合，所以此例判為原文有誤，不據以改算法。
